# Technical Architecture & System Design Document
**System Architecture:** Modular Monolith (Domain-Driven Design / DDD-Lite)  
**Backend Framework:** Laravel 11+ (PHP 8.3+)  
**Primary Database:** PostgreSQL 16+ (Utilizing JSONB & Pessimistic Row Locking)  
**Cache & Task Queue:** Redis 7+  
**Admin Engine:** Filament PHP v3  
**Frontend Framework:** Angular 19+ with Server-Side Rendering (`@angular/ssr`) OR Full-Stack Laravel (Blade + Livewire v3)  

---
